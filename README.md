# Bend of the Elements

Bend of the Elements is a Minecraft plugin that adds water, fire, earth, and air bending abilities to the game. Players can learn and master these bending arts, use them in combat, and explore new gameplay mechanics. The plugin includes animated abilities, flying mechanics, custom items, and Avatar characters, providing a rich and immersive bending experience.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server to load the plugin.

## Use

1. Join a Minecraft server with the Bend of the Elements plugin installed.
2. Use the `/ciao` command to greet the server and receive a welcome message.
3. Explore the world to find bending temples and learn new abilities.
4. Use your bending abilities in combat, exploration, and other gameplay scenarios.
